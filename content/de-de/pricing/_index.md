Die Preise für Seraphin IoT basieren auf einem Pay-as-you-go-Modell (PAYG). Ihnen werden folgende Kosten in Rechnung gestellt:

- Registrierung neuer Geräte
- Telemetrieereignisse verarbeiten
- Benachrichtigungen

Ihr Preisplan hängt von Ihrer Bereitstellung ab.

#### Preisgestaltung

Die kostengünstigste Option für Privatanwender wäre die Nutzung unserer Shared Cloud gemäß unseren allgemeinen Geschäftsbedingungen. Dies ist die beste Option für IoT-Enthusiasten oder potenzielle Kunden, die unsere Plattform evaluieren möchten.

#### Vollständig verwaltet

Wenn ein Kunde IoT-Dienste vollständig auslagern möchte, prüfen wir den Standort, wählen die geeigneten IoT-Geräte aus, konfigurieren die Verbindung zur Cloud und nehmen den Kunden – je nach Anzahl der installierten Sensoren – in eine gemeinsam genutzte Cloud auf oder stellen eine isolierte Umgebung bereit, die ausschließlich dem Kunden zur Verfügung steht. Unsere Dienste können im Rahmen einer gemeinsamen oder einer individuellen Vereinbarung mit Allgemeinen Geschäftsbedingungen erbracht werden.

#### Nur Software

Dies ist eine ideale Option für Kunden, die bereits eine große IoT-Implementierung an ihren Standorten verwalten. Seraphin IoT kann als SaaS-Produkt bereitgestellt werden, wobei vorhandene IoT-Geräte für die Nutzung der Plattform konfiguriert werden. Der Kunde bleibt für die Hardware verantwortlich und erhält eine erweiterte Rolle auf der Seraphin-Plattform, sodass er neue Benutzer frei hinzufügen, neuen Benutzern Rollen zuweisen, neue Geräte registrieren und die volle Kontrolle über die Daten innerhalb der Plattform sowie Zugriff auf Audits haben kann. Unsere Dienstleistungen werden im Rahmen einer individuell angepassten AGB-Vereinbarung erbracht.
